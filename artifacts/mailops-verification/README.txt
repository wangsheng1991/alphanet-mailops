DLSS5 Studio MailOps — Delivery Verification Package
====================================================

This small package validates the complete private-delivery workflow:

1. a request enters the MailOps review queue;
2. an administrator selects an active build;
3. MailOps emails a time-limited, download-count-limited link;
4. the link streams this file through download.alphanetplus.com;
5. the download is written to the audit trail.

This is NOT the DLSS5 Studio application or NVIDIA runtime. The private
Studio build is intentionally not included. Replace this verification build
with the authorised Windows package when that file is available.

Service: https://mailops.alphanetplus.com
Download gateway: https://download.alphanetplus.com
Issued: 2026-10-02
